# Weather_Parser

Консольная утилита на Python, которая загружает список городов из файла, получает по каждому городу текущую погоду через публичный API
[wttr.in](https://wttr.in) и выводит:

1. Погоду по каждому городу в формате `City, Country +18°C`.
2. Сводную статистику по странам: количество городов, средняя,
   минимальная и максимальная текущая температура.

## Требования

- **Python 3.10+** (используется синтаксис `list[str]`, `dict | None`).
- **Только стандартная библиотека.** Внешние пакеты не используются.
  Разрешённые модули: `json`, `time`, `urllib.request`, `urllib.parse`.
- Доступ в интернет (запросы идут на `https://wttr.in`).

## Формат файла `Cities.txt`

- Один город на строку.
- Кодировка — UTF-8 (допускается UTF-8 с BOM — скрипт умеет его срезать).
- Пустые строки игнорируются.
- Дубликаты городов удаляются автоматически (по заданию нужны уникальные города).

Пример:

```
Moscow
Khabarovsk
Saint-Petersburg
Vienna
Izhevsk
Perm
NhaTrang
Villach
```

## Запуск

```bash
python main.py
```

Скрипт последовательно опрашивает API, печатает прогресс по каждому
городу и в конце выводит статистику по странам.

## Как это работает

### 1. Загрузка городов

`load_cities(path)` читает файл в кодировке `utf-8-sig`, убирает пробелы и пустые строки, возвращает
`list[str]`.

В `main` список прогоняется через `dict.fromkeys(...)` — так убираются
дубликаты с сохранением порядка.

### 2. Запрос к API

`fetch_weather_API(city)`:

- URL-кодирует имя города через `urllib.parse.quote` (пробелы → `%20`);
- делает GET-запрос к `https://wttr.in/{city}?format=j1`;
- обязательно передаёт заголовок `User-Agent` — без него `wttr.in`
  нередко отдаёт `403 Forbidden`;
- ограничивает время запроса 15 секундами;
- возвращает распарсенный JSON (`dict`) или `None` при ошибке.

### 3. Модель `WeatherData`

Простой класс с тремя полями:

| Поле       | Тип    | Описание                              |
|------------|--------|---------------------------------------|
| `city`     | `str`  | Название города                       |
| `temp`     | `int`  | Текущая температура в градусах Цельсия|
| `country`  | `str`  | Страна                                |

Метод `__str__` отвечает за формат вывода в пункте 4:
`City, Country +18°C` (знак всегда показывается благодаря формату `+d`).

### 4. Парсинг ответа

`parse_weather(city, city_data)` вытаскивает из JSON два поля:

- `current_condition[0].temp_C` — **строка**, поэтому конвертируется в `int`;
- `nearest_area[0].country[0].value` — страна.

Если структура неожиданно другая, ловится исключение и функция
возвращает `None`. Один «плохой» город не ломает весь прогон.

### 5. Группировка и статистика

`group_by_country(weather_list)` собирает словарь
`{country: [temp1, temp2, ...]}` через `dict.setdefault`.

`print_country_stats(...)` по каждой стране считает:

- количество городов — `len(temps)`;
- среднее — `sum(temps) / len(temps)`;
- минимум — `min(temps)`;
- максимум — `max(temps)`.
